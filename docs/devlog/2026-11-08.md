## 결정
- **휴대폰은 `schema_version` ≥ 1(PC v1.8.0 이상) 파일만 받음**: 예전 구조 보완(마이그레이션)은 PC 가 맡아 JS 로 옮길 코드를 줄임. 예전 파일이면 "PC 를 v1.8.0 이상으로 실행한 뒤 다시 내보내기" 안내
- 불러오기는 '수정'이 아니므로 파일의 `last_modified` 를 그대로 유지 (PC 복원과 동일)
- 불러오기 직전 장부를 IndexedDB `before_import` 에 1개 보관
- `vendor/sql.js/package.json`(`commonjs`): 저장소가 `"type": "module"` 이라 Node 테스트에서 sql.js 를 CommonJS 로 읽게 함 (브라우저 영향 없음)

## 검증
- PC 와 숫자 대조: 같은 파일(PC 샘플 3개월 + 실제 장부 복사본 13개월)에서 대상자·납부율·회비 수입·확인 중·미납 목록·월 증감·잔액 **16개 달 모두 일치**
- Edge(Chromium) 헤드리스 + DevTools 프로토콜, 390×844 휴대폰 화면: 첫 화면 → 파일 선택 → 확인 창(체크 전 버튼 잠김) → 대시보드 → 새로고침 후 유지 → 오래된 파일 경고(확인란 2개 체크해야 버튼 열림)
- 참고: 헤드리스 `--virtual-time-budget` 은 WebAssembly·IndexedDB 를 기다리지 않아 '불러오는 중'에서 찍힘 → DevTools 프로토콜로 검증. 디버깅 포트(9333)는 다른 프로그램이 쓰고 있을 수 있으니 다음에는 빈 포트를 쓸 것
